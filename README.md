# Trainer Card Studio

Mobile-first manual trainer card editor inspired by the template workflow used by sites like Carrd.

## v24 — Zero AI

- No OpenAI, generative AI, OCR, character recognition, or automatic background-removal model is used.
- Choose a fixed **Valor**, **Mystic**, or **Instinct** card template.
- Type trainer name, level, buddy, activity stats, start date, print date, and trainer code manually.
- Upload your own trainer image, buddy image, and QR image.
- Uploaded images are placed as-is. Transparent PNGs work best.
- Drag the selected trainer or buddy directly on the front preview, or use the zoom / horizontal / vertical controls.
- Adjust background vertical position, background zoom, ground/contact line, and grounded vs flying/floating buddy placement.
- Flip between front and back.
- Export a high-resolution PNG or an optional 4-second animated team-effect version.

## Privacy / processing

The editor runs in the browser. It does not send uploaded images or trainer information to an AI service or backend. The production page only combines the user-entered text, user-uploaded images, and the fixed team templates.
